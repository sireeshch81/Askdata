# ML Recommendation System

## 🎯 Overview
Machine Learning-powered recommendation system that generates personalized financial product recommendations using scikit-learn similarity clustering.

## ✅ Features
- **37+ ML features** extracted from Data Warehouse star schema
- **KNN + K-Means + PCA clustering** for similarity analysis
- **23+ customers/second** processing speed
- **99.8% model variance** explained
- **Secure MongoDB** authentication
- **Docker integration** with existing infrastructure
